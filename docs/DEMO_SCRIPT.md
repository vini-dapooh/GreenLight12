# 3-5 minute demo script
1. (0:00) Problem in one line: artwork is checked by eye against a spreadsheet; mistakes cost a print run.
2. (0:20) Open the app, click **Load the Dancing Fish sample** (or drop carton.pdf + content sheet + rulebook). Mention ~15 s.
3. (0:50) Verdict banner: *Not ready to launch* - 15 definite problems, 13 need a human, 8 correct.
4. (1:10) Click the **%DV math** finding: the arithmetic table and the pin on the panel.
5. (1:50) **No Added Sugar** vs honey/coconut sugar: two evidence pins, one claim and one ingredient.
6. (2:20) **Hidden UK table**: toggle Dieline off; explain text layer vs OCR. Note it is REVIEW, not FAIL: the system says why it is unsure.
7. (3:00) **Uncertainty**: open a REVIEW item and a manual company clause; show confidence, tags, Confirm / False alarm.
8. (3:30) Ask a follow-up in a finding's Ask box; mention LLM layer is optional and capped at REVIEW.
9. (4:00) Export HTML/CSV; close on architecture: deterministic core, AI where it helps, never the sole judge.
